# AI 数据可视化的共用基础

当前入口是 AI 小脏回答与数值表格的“生成图表”。采用 Apache ECharts 6 的按需模块与 SVG 渲染，图表代码仅在需要图表时加载，不请求 ECharts 外部 API。

数据链路：模型结构化数据 → `assistantChartSchema` 验证 → `resolveChartPresentation` 选择类型 → `makeEChartsOption` 生成受控配置 → `EChartsPlot`。裸 JSON、JSON 围栏和旧消息兼容由 `assistant-chart-markdown` 保留。

类型优先级：用户明确要求优先；无指定时，有序时间轴用折线、同一整体的构成用饼图、类别比较用柱状图。百分比并不一定代表构成。缺失值不补零，多个系列或负数不能硬拼成饼图。图表不编造市场份额，模拟数据必须标注。

后续独立板块建议放在“AI 办公工具体验 → 表格与数据分析”中，沿用上述模块。用户选择数据范围、维度、指标与单位，先预览数据，再生成图表；明确用户映射之后，才扩展散点、堆叠、热力等类型与对应验证规则。无需为聊天和工作台分别维护渲染器。

搜索工作台可为图表提供数值来源，但不能把宣传数字、不同统计周期或未知分母的比例自动合并。后续扩展来源编号时，需要同时更新数据 schema、引用核验和导出链路。
